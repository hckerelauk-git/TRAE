核心能力

不止是聊天机器人

从 Agent 编排到知识库检索，从情感陪伴到自动化任务，AstrBot 为你打造完整的智能助手体验

Agentic 基础设施

完整的 Agent 运行时，支持子 Agent、复杂工作流、工具调用与上下文管理，让 AI 真正执行任务。

  • MCP 协议原生支持
  • Skills 技能模块
  • Agent 沙箱环境
  • 定时任务 Cron

知识库系统

内置知识库能力，让你的 Bot 快速理解领域数据。支持 PDF、DOCX、Markdown 等多种格式高质量解析。

  • 混合检索（稠密 + BM25）
  • 多知识库引用
  • 中英文优化
  • Markitdown 解析

情感陪伴

温暖、有情绪感知的互动体验。倾听你的声音，记住你的偏好，主动关心你的日常生活。

  • 分段回复 + 主动对话
  • 人格设定轻松编辑
  • 长期记忆系统
  • 好感度系统
